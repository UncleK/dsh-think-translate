# 1.2.19

- Add a glossary for each of the nine target languages. Enter one `source => target` pair per line, with up to 128 entries per language. English terms match whole words without case sensitivity; longer terms take priority. Saving affects only the selected language; a global switch preserves entries while disabling them.
- Protect glossary terms after separating code, paths, URLs and commands. Validate provider tokens before restoring exact target terms; damaged tokens trigger the next provider and total failure retains the original text. Keep multiword terms intact across long-text chunks. Glossary changes invalidate host and browser caches.
- Store manually entered API keys through the DSH credentials service and retain only references in plugin configuration. Migrate legacy literal keys when the service becomes available, redact configuration responses, preserve keys on blank edits and require an explicit clear action. Serialize configuration updates and replace the file atomically. This uses the host credential service, not an OS keychain claim.
- Include provider settings and credential revisions in cache namespaces; reject stale in-flight responses. Upgrade browser translation storage to v6 while preserving preferences.
- Keep this plugin and the official thinking translator mutually exclusive. Detect effective official-plugin activation, stop our translations, withdraw our display overrides and show a localized notice. Recheck periodically and resume when the official translator is disabled, without changing its configuration.
- Extend code protection to recognizable bare paths, URLs, filenames and common commands. Ambiguous commands should still use Markdown code formatting. Translation remains display-only and retains original content.
- Add GitHub Actions tests for Linux/Windows and Node 20/22/24/26, with pinned Actions and read-only repository permissions. Preserve the existing Codex forwarding workflow.
- Update the version and all nine localized READMEs. Preserve the existing demo assets.

Validation: 475 tests passed locally on Node 24.22.2 and Node 20.20.2. Live DSH Web checks covered saving and reloading glossary entries, a real Google translation with exact fixed terms, changing terms and retranslating the same input, code/path/URL preservation, and clearing temporary test entries. The Web profile retained its other dependencies and provider/key settings. Automated tests additionally cover malformed entries, fallback, credential migration failures, stale caches and official-plugin mutual exclusion. Remote matrix results are reported separately by GitHub Actions.

GitHub assets and npm registry publication are separate delivery states. This release does not implement paragraph controls, streaming translation or simultaneous operation with the official translator.
