# 1.2.23

- Start translating later reasoning blocks when their first nonblank text arrives, including while the turn is still streaming ([#23](https://github.com/UncleK/dsh-think-translate/issues/23)).
- Restore the checklist and expand/collapse icons in the todo dock on newer DSH versions. Older icon exports remain supported ([#24](https://github.com/UncleK/dsh-think-translate/issues/24)).
- Translate common CJK slash expressions such as `输入/输出` and recognize explicit prose continuations after known file extensions. Mark off a bare URL with backticks, a space or full-width punctuation when prose immediately follows it. Unmarked text can be part of a valid URL slug ([#22](https://github.com/UncleK/dsh-think-translate/issues/22)).

首次从 1.2.21 或更早版本升级时，先按 [1.2.22 的迁移说明](https://github.com/UncleK/dsh-think-translate/releases/tag/v1.2.22) 复制一次旧配置。
