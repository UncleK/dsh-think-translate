# 1.2.21

Fix repeated translation requests when task text changes rapidly ([#17](https://github.com/UncleK/dsh-think-translate/issues/17)). The task card shows the original text while tool arguments are being prepared. Uncached task text in the card and composer dock is translated after 500 ms without changes, and a pending timer is cleared when its text changes or the component unmounts.

In a controlled component test, 28 text updates previously sent 28 requests. The fix sends one request containing the final text after it settles. Long-running memory use and model unload behavior remain open for retesting in the reporter’s Ollama environment.

Validated with 484 plugin tests and all eight [remote CI jobs](https://github.com/UncleK/dsh-think-translate/actions/runs/42164010899). DSH `0.2.2-rc.1` at `fcc0ad4621` passed all ten build gates. The packed plugin rendered translated task summaries, expanded task items and the composer dock in an isolated Web profile. During a 28-update dock burst, the loopback test provider received one request containing the final text.
