# 1.2.22

- Store translation settings under the active DSH profile so replacing the plugin package preserves the provider chain, glossary and credential references ([#21](https://github.com/UncleK/dsh-think-translate/issues/21)).
- Use a shorter glossary term when a longer one fails its word boundary. For example, `task cards` can match `task`, while `task card` still matches the longer entry ([#20](https://github.com/UncleK/dsh-think-translate/pull/20)).

**Before updating from 1.2.21 or earlier**, stop DSH. In the active profile, if `node_modules/dsh-think-translate/lib/config.json` exists, copy it to `dsh-think-translate/config.json` before updating. Create the directory if needed and keep the destination if it already exists. The plugin manager can remove the old package during an update. This step is only needed once per profile.

**从 1.2.21 或更早版本升级前**，先退出 DSH。如果当前 profile 中有 `node_modules/dsh-think-translate/lib/config.json`，请在更新前把它复制到同一 profile 下的 `dsh-think-translate/config.json`。需要时先建目录，目标已存在则保留。每个 profile 只需复制一次，之后升级会保留仅本地模型设置、术语表和凭证引用。
