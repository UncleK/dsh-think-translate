# 1.2.20

- Add an optional built-in glossary of 60 common English AI/programming terms and product names, localized for all nine target languages. Preview the list in settings or the standalone translation page.
- Use separate checkboxes for built-in and custom entries, placed in their respective sections. Each checkbox saves immediately and operates independently. Disabling either preserves saved custom entries. Active custom entries override matching built-ins without consuming the separate allowance of 128 custom entries per language.
- Show unsaved-edit reminders, highlight Save, and retain per-language drafts when switching languages. Remind users about unsaved drafts in other languages. While the editor is mounted, warn before refreshing or leaving the webpage with unsaved drafts; remove the warning after saving or reverting.
- Span the full page width with the glossary card. Use side-by-side preset/editor sections and horizontal runtime statistics on wide screens, and one column in narrow windows and settings dialogs.
- Include the preset content fingerprint and independent-switch behavior revision in cache namespaces. Retain code/path/command protection, provider fallback, credential protection and mutual exclusion with the official translator.
