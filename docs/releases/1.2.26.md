# 1.2.26

- Show the DSH provider's display name and configured model in translation settings, for example `OpenRouter · openrouter/free`. Providers without a display name use their provider ID. The translation order continues to use the provider IDs.

## 中文

- 翻译设置显示 DSH 提供方的显示名称和已配置的模型，例如 `OpenRouter · openrouter/free`。没有显示名称时使用提供方 ID，翻译优先级仍按提供方 ID 保存。

首次从 1.2.21 或更早版本升级时，按 [1.2.22 的迁移说明](https://github.com/UncleK/dsh-think-translate/releases/tag/v1.2.22) 复制一次旧配置。
