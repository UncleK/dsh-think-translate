# 1.2.24

- Serialize DSH provider rescans with provider configuration saves so a stale scan cannot overwrite a newly saved API key reference ([#25](https://github.com/UncleK/dsh-think-translate/pull/25)).
- Require a same-origin POST and, on hosts with login checks, a valid DSH session for rescans. Cross-origin requests are rejected and legacy GET requests receive HTTP 405 ([#18](https://github.com/UncleK/dsh-think-translate/pull/18)).

## 中文

- 重新扫描 DSH 配置和保存提供方共用同一个写入队列，防止扫描时读到的旧配置覆盖新保存的 API Key 引用。
- 扫描入口改为同源 POST，支持登录检查的宿主同时要求有效的 DSH 会话。旧版 GET 返回 405。

首次从 1.2.21 或更早版本升级时，按 [1.2.22 的迁移说明](https://github.com/UncleK/dsh-think-translate/releases/tag/v1.2.22) 复制一次旧配置。
