# 1.2.25

- Fix Windows proxy detection when a proxy tool writes registry value names with different capitalization. When the registry has no enabled proxy or cannot be read, use HTTPS_PROXY or HTTP_PROXY for translation requests ([#26](https://github.com/UncleK/dsh-think-translate/issues/26)).

## 中文

- Windows 翻译请求可以识别不同大小写的系统代理注册表值名。系统代理未启用、缺失或注册表读取失败时，会读取 HTTPS_PROXY 或 HTTP_PROXY。

首次从 1.2.21 或更早版本升级时，按 [1.2.22 的迁移说明](https://github.com/UncleK/dsh-think-translate/releases/tag/v1.2.22) 复制一次旧配置。
