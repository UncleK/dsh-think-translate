# Issue #17：本地模型释放与超时排查

Issue：[Ollama 本地模型空闲释放与 was aborted](https://github.com/UncleK/dsh-think-translate/issues/17)。报告环境为 DSH 0.2.1-rc2、插件 1.2.16，截图模型为 `kaelri/hy-mt2:1.8b-q4_K_M`。

## 已确认并修复的两个缺陷

### 已加载模型的空闲策略没有随保存更新

复现步骤：先关闭自动释放并执行一次翻译，让模型常驻；随后改成 30 分钟，不再发送翻译。旧实现只在下一次模型请求中附带新 `keep_alive`，配置保存不会更新已经驻留的模型。实测 `/api/ps.expires_at` 仍为 2319 年，模型不会在所选的 30 分钟后卸载。

现在保存变化后的时长，会等待本插件的既有翻译和准备任务结束，只为已加载的所选模型提交新策略。未加载的模型不会因此被加载。策略更新和手动释放按序执行，新翻译等待维护完成；旧请求无法在新策略之后重新写回常驻设置。

### 本地推理被固定限制为 15 秒

原生 `/api/chat` 请求使用 15 秒超时，慢速 CPU、较长文本或服务端排队都可能触发。响应头已到达但正文尚未完成时也会中断，最终出现泛化的 `was aborted`。

本地推理期限改为 120 秒，超时明确返回 `Ollama translation timed out after 120 seconds`。浏览器等待 Host 的期限调整为 300 秒，覆盖模型准备和推理。远程提供方的期限保持原状，关闭的提供方不会被启用，失败时仍保留原文。

真实 HTTP 延迟正文回归使用 100 倍时间压缩，模拟 25 秒响应：旧 15 秒期限触发超时中断，新期限成功读完正文。这是可控延迟测试，不是对提问者机器性能的测量。

## 已完成验证

- 生命周期、错误恢复、语言守卫、代码保护和客户端组件测试通过。
- Ollama 0.32.15 上，同款 Hy-MT2 Q4_K_M 模型完成三段长短文本的中文翻译；完整提供方链的代码块样本也成功，代码保持原样。
- 同款模型从常驻改为 1 分钟，在约 60 秒真实空闲后从 `/api/ps` 消失；常驻改为 30 分钟后过期时间立即更新为当前时间加 30 分钟。
- 1.2.17 最终 tarball 在 DSH 0.2.2 的隔离 Web 与原生 Electron profile 中分别安装并挂载实际插件设置组件，真实 Host 保存、翻译、代码保留、策略变更、剩余时间显示和手动释放均通过，未捕获插件脚本错误。405 项测试通过，没有替换用户现有 Web/Desktop profile。

## 1.2.17 验证范围

本次短样本中，`/api/ps` 对该模型报告约 1.35 GiB、4096 token context，数次翻译后保持不变。该数值是 Ollama 的模型驻留大小，不能当作 Windows 进程 RAM、全部 VRAM 或整个 Ollama 服务的内存占用。

这轮短样本没有覆盖报告者的长期负载，也未在 DSH 0.2.1-rc2 上复测。上述 Web/Electron 验证使用 DSH 0.2.2。

## 2026-11-06 跟进：待办翻译请求过密

UNIEPOpep 在 Ollama 0.40.13、插件 1.2.17、纯 CPU 的环境下记录了约 57 分钟的数据。`llama-server` 的工作集在约 9.6 GB 进入平台期，同模型同配置上一轮的日志记录了 8192 MiB 提示缓存上限和接近上限的占用。报告用 `/slots` 的任务编号变化估算了约 28.5 次/秒的活动速率。这些证据支持该次内存上涨主要来自提示缓存被填满。 [详细复测](https://github.com/UncleK/dsh-think-translate/issues/17#issuecomment-6625701511)

当前源码的三个待办入口原先随每次文本变化立即请求。已有去重只覆盖相同文本，连续变化的片段会产生不同键。修复后，会话待办摘要和展开项在 `preparing` 阶段显示原文，开始执行或已结束后可翻译。输入框上方待办栏只接收 `todos` 投影，没有工具阶段信号。三个入口都在未命中成功缓存时等待文本稳定 500 毫秒。文本变化和组件卸载会撤销待发送的计时器，译文只显示在对应的原文及配置键上。已经送达 Host 的请求沿用现有处理流程。

用实际注册的前端组件和可控时钟复现了待办栏在约一秒内变化 28 次。旧客户端向模拟 Host 发出 28 次请求，修复后在变化期间发出 0 次，稳定 500 毫秒后发出 1 次，内容是最终文本。另验证了准备中的摘要与展开项不发送请求、开始执行后相同内容去重，以及卸载前取消尚未发送的请求。全套 484 项测试通过。

在与远端 `master` 一致的 DSH `0.2.2-rc.1`（`fcc0ad4621`）上完成 10 项构建检查。隔离 Web profile 加载了 1.2.21 安装包，待办摘要、展开项和输入框待办栏都显示译文。向真实宿主注入 28 次待办更新，回环测试提供方只收到一次最终文本。该测试使用模拟模型端点。 [1.2.21 发布记录](releases/1.2.21.md)

原机器上的长期内存和卸载仍待复测。应在同模型和 CPU 环境下对照请求速率、插件活动租约数、`llama-server` 工作集及 `/api/ps`，并单独核对返回 `done_reason: "unload"` 后模型仍列在 `/api/ps` 的情况。该返回值与实际驻留状态需要分开记录。
